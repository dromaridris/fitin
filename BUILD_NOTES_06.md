# Smart Recipe & Nutrition App — BUILD 06

Flutter mobile foundation for:
- Recipe Details
- Missing Ingredients
- Serving Calculator
- Nutrition display
- What Do I Have? recommendations screen
- Arabic / English / Roman Urdu UI foundation
- RTL support for Arabic

This is the first mobile UI layer connected conceptually to the backend API contract.

## Flutter
Run:
flutter pub get
flutter run

The API base URL is configurable in lib/config/app_config.dart.

For Android emulator use:
http://10.0.2.2:8000/api

For iOS simulator use:
http://127.0.0.1:8000/api
