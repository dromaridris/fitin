# FITIN by LARC

London Aesthetics & Rejuvenation Centre — recipe & nutrition companion.

Merged project combining all build stages (BUILD01 → BUILD15) plus the
FITIN by LARC rebrand pass, into one unified codebase.

## Structure
- `backend/` — FastAPI + SQLAlchemy backend (recipes, ingredients, nutrition engine, search, recommendations, admin CRUD, nutrition profiles, daily calorie log)
- `flutter/` — Flutter mobile app, FITIN by LARC branded (Home, Search, What Do I Have, Recipe Details, Nutrition, Nutrition Dashboard/Today, Favorites)
- `admin/` — Web admin dashboard (HTML), backed by the same CRUD API
- `docker-compose.yml` — PostgreSQL + backend + seed service definitions
- `BUILD_NOTES_01.md` … `BUILD_NOTES_15.md` — original notes from each build stage, kept for history

## Brand
- App name: **FITIN by LARC**
- Colors sampled directly from the official LARC logo: black `#000000`, gold `#CFB555`, white `#FFFFFF`
- Central design system: `lib/theme/` (`AppColors`, `AppTypography`, `AppTheme`) + `lib/widgets/` (`Larc*` reusable components)
- Logo bundled locally at `flutter/assets/images/larc_logo.png` — never fetched from network

## Run with Docker (backend)
```bash
docker compose up --build
```
API: http://localhost:8000 — Swagger: http://localhost:8000/docs

## Run backend locally
```bash
cd backend
python -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --reload
python -m app.seed
```

## ⚠️ Known limitation: Android platform folder
This project has never had `flutter create` run against it, so there is
**no `android/` directory** — meaning no Gradle/Kotlin/AGP scaffold exists
yet, and no APK has ever been built from this codebase. This must be
generated by an environment with the actual Flutter SDK installed, e.g.:
```bash
flutter create .
```
run from inside `flutter/` (this preserves the existing `lib/`, `assets/`,
and `pubspec.yaml` — it only fills in the missing platform folders). Do
not hand-write the Android Gradle files; let the Flutter SDK generate them
so they match your installed Flutter/AGP/Kotlin versions.

Once `android/` exists, set `android:label="FITIN by LARC"` in
`android/app/src/main/AndroidManifest.xml` and replace the launcher icons
under `android/app/src/main/res/mipmap-*/` with the LARC logo.

See the final status table in the project delivery notes for exactly
which features are implemented vs. tested vs. blocked.

## Notes
Since the builds were generated as separate incremental stages, some files may
overlap in responsibility (e.g. `services/nutrition.py` vs `services/nutrition_engine.py`,
or `models/entities.py` vs `models/ingredient.py` / `models/recipe.py`). Review
`backend/app/` before deploying to resolve any duplicate/overlapping logic.
