# Smart Recipe & Nutrition App — BUILD 12

Admin + User Nutrition Profile foundation.

This build adds:
1. Admin dashboard foundation for ingredients and recipes.
2. User nutrition profile:
   - age
   - sex
   - height
   - weight
   - activity level
   - breastfeeding flag (optional)
3. BMI calculation.
4. Estimated BMR and TDEE.
5. Daily calorie target.
6. Daily calorie logging.
7. Remaining calories indicator.
8. Protein / carbs / fat targets.
9. Progress dashboard.
10. Clear separation:
    - BMI is a screening indicator, not a diagnosis.
    - Nutrition Engine remains the source of recipe nutrition values.
    - AI is not used to calculate BMI or calories.

Important:
The calorie target is an estimate. The app should display it as an estimate and allow a user or qualified professional to adjust it.
For breastfeeding users, the app should avoid aggressive calorie deficits and should not present weight-loss targets as medical advice.
